# Cryptography and Web Security - Practical Work 1

This repository contains the implementation for the first practical work of the **Cybersecurity** course at **Universitat d'Andorra**.

The project focuses on the implementation and analysis of different cryptographic systems, including classical ciphers, symmetric and asymmetric encryption, hashing, integrity verification, and cryptanalysis techniques.

## Contents

The project includes:

- Classical encryption algorithms
- Custom cipher implementation
- AES and RC4 encryption/decryption
- RSA-based secure communication
- Digital signatures
- Man-in-the-Middle attack simulation
- File hashing and integrity verification
- Cryptanalysis experiments
- Technical report written in LaTeX

## Technologies

- Rust
- Cargo
- OpenSSL and cryptographic libraries
